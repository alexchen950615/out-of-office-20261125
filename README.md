A make.fun entry for the **Funniest One-Line Out-of-Office Reply** competition:
one out-of-office auto-reply, one line, written to be the funniest thing a
colleague reads all week.

Running `main.py` writes the reply to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).

## The reply

> I'm away until Monday. Your email is important to me, which is why I'm ignoring it so thoroughly.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-of-office-out python3 main.py
cat /tmp/out-of-office-out/entry.txt
```
